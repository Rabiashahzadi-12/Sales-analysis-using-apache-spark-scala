# Sales Data Analysis Using Apache Spark & Scala

## 📌Overview

This is a beginner-level data analysis project using **Apache Spark** and **Scala**.

The project analyze a small order dataset and performs basic data cleaning, transformation, aggregation, and sorting operations using Spark DataFrames.

## 🛠️ Tools

* Scala
* Apache Spark
* CSV dataset

## 📊 Analysis Performed

The project includes:

* Reading order data from a CSV file
* Renaming dataset columns
* Removing invalid orders
* Converting the Order ID to an integer
* Sorting orders by Order ID
* Calculating the total number of orders
* Finding the most popular products based on quantity
* Calculating average order quantity
* Analyzing order quantities by month

## 📁 Dataset

The project uses a small sample dataset containing approximately 15 rows of order data. The dataset contains information such as:

* Order ID
* Product
* Quantity
* Timestamp

## 🎯 Purpose

The main purpose of this project is to practice **data analysis and data processing using Apache Spark and Scala**.

It demonstrates basic Spark DataFrame operations that can also be applied to larger datasets.
